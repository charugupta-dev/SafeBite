# SafeBite 🥑🛡️

An AI-powered food item and ingredient safety scanner built with Flutter and Python.

## Overview
SafeBite analyzes food items against customized health profiles (e.g. babies, seniors/parents with dietary conditions, personal allergies/intolerances) using AI tool calling and reasoning to provide quick, actionable safety verdicts.

### Structure
- `safebite_app/`: Flutter mobile client (iOS / Android / macOS / Web)
- `safebite_backend/`: FastAPI backend powered by OpenAI / Groq tool-calling agents
